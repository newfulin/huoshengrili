# 如何更新小花生日程安排

## 数据会不会丢？

**一般不会。**

- 程序装在：如 `C:\Users\你\AppData\Local\小花生日程安排\`（以安装器为准）
- **数据在**：`文档\小花生日程安排\data.json`（与安装目录分开）

覆盖安装 / 重新跑 setup.exe，通常**不会删**「文档」里的数据。

但仍建议更新前在 App 侧栏点一次 **导出数据** 备份。

## 推荐更新方式（合适）

1. 开发机改代码 → 在 Windows 再打包出新的 `*-setup.exe`
2. 用户电脑：**直接再装一遍新 setup.exe**（不必先卸载）
3. 打开软件确认事项还在；不行就用「导入数据」恢复备份

## 不推荐

- 先卸载再装（多数情况多余；若卸载器勾选删用户数据才有风险）
- 手动删整个「文档\小花生日程安排」文件夹

## 其他方式（进阶）

| 方式 | 说明 |
|------|------|
| 覆盖安装 | 最合适，日常更新用这个 |
| 导出/导入 JSON | 换电脑、重装系统时用 |
| 直接拷贝 data.json | 高级用户可把数据文件拷到新电脑同路径 |
